This pipeline takes a large and unorginazed CSV file and cleans it up. You run it from the command line and tell it which file to read, where to save the result, and which config file to use. First it makes sure those files actually exist and loads them. Next it checks that the data has the columns it needs and throws out any rows where a number isn’t really a number. Then it cleans the data by removing duplicates, rows with missing values, and outliers, all based on what’s in the config file. Last, it saves the clean data to a new CSV and prints a short report of what changed. The code is split up so each file has one job: data_loaders.py reads files, data_validator.py checks the data, data_processor.py cleans it, data_output.py saves it, and utils.py handles logging and checking that files exist. pipeline.py just ties them all together.
